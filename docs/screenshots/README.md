# Screenshots

Generated by `shots/ModDbShots.cs`, not hand-taken, so the set can be reproduced after a
visual change:

```bash
cd ../vstestkit
bash scripts/run.sh ../fornax/shots --mod ../fornax/fornax --client
```

Three things the shots need that a normal test run does not, and that the script handles:

- **Particles.** vstestkit's client template sets `renderParticles: false` for deterministic
  visual baselines, so a stock run photographs no smoke at all. Boot with a template that
  enables it (and a larger `screenWidth`/`screenHeight`) and restore the template afterwards.
- **The HUD.** `ICoreClientAPI.HideGuis` is read-only, but the minimap, block tooltip and
  interaction help are `GuiDialog`s and close on request. The hotbar and stat bars reopen
  themselves and are cropped off instead. Ordinary first person floats the seraph's hand in
  frame; `immersiveFpMode` keeps it out.
- **Fog.** Distance haze washes the horizon out. It comes from the ambient manager, not a
  render setting, so it is overridden with an `AmbientModifier` at full weight.

Plots sit `Plots.Spacing` (48) apart, so a plot of that size touches its neighbour and the
previous test's blocks appear just past the boundary. The scenes clear well past the plot edge.
